Orchestrating session
Reads the release-type graph and status.md, works out what can run, applies the budget, and dispatches one lane per runnable artifact. Two artifacts with no dependency between them run at the same time.
lane brief: task, owned directory, state file, budget, report once
report once: complete, stalled, or needs a ruling
conceptual_model
Agent data-designer. Runs conceptual_model-generate.
Writes only inside design/ and its own state file.
dbt-developer [staging 1/2]
Agent dbt-developer. Runs dbt-generate for its 5 models.
Writes only inside dev/ and its own state file.
dbt-developer [staging 2/2]
Agent dbt-developer. Runs dbt-generate for its 5 models.
Writes only inside dev/ and its own state file.
The record
The orchestrator reads each lane's state file, checks the work, and alone writes status.md and execution_log.md. Lanes never spawn sub-agents and never write those two files.
