3
Artifact write
inside the owned tree only: dev/models/staging/; files committed by name
4
Validate
dbt-generate sets auto_validate: false: validate runs live dbt, so it runs as its own step before review
5
State file
rewritten after each completed item, not at the end; a restart reads it and skips what is done

MCP servers
BigQuery for schema checks against the source; GitHub for the repo. Falls back to the bq tool per call if the server is unreachable.
Bash
dbt to compile and test; git to commit the owned files by name, never git add -A.
Git worktree
One worktree per branch. The main delivery checkout is never switched under a running set of lanes.
File system
The .wire/ tree is the system of record; git is its history and transport.
